# graph_recompress
Hypergraph Grammar Recompression approach

See the evaluate/roundtrip directory for examples on how to use this project.
This project only contains Python Code, it does not contain the tested data.
For the tested data, see the links in the paper/dissertation.

The classes are in the classes directory, the code for the recompression is in recompress.
Input and Output from the classes is in inout.
